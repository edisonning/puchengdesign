# 蒲城县交通运输运行监测总览

面向蒲城县交通运输指挥中心的单页运行监测大屏。设计基准为 3840×1080，首屏完整呈现路网、营运车辆、工程建设、货运、实时车辆地图、报警与 12328、视频监控、城市交通等信息。

## 本地运行

```bash
npm install
cp .env.example .env.local
npm run dev
```

在 `.env.local` 中配置百度地图浏览器端 AK 和已发布的个性化地图样式 ID：

```dotenv
VITE_BAIDU_MAP_AK=your_browser_ak
VITE_BAIDU_MAP_STYLE_ID=your_published_style_id
```

请在百度地图控制台为该 AK 配置正确的 Referer 白名单。个性化地图样式必须已发布，并且与 AK 属于同一个百度地图账号。深色主题无法加载时页面会保留可操作的百度标准底图并提供独立主题重试；未配置 AK 或地图服务不可用时，页面会显示可操作的降级态势底图，不会出现空白区域。

## 数据说明

当前业务数据集中存放在 `src/mock/`，全部为固定、可复现、数量级合理的模拟数据，不代表蒲城县真实运营数据。车辆初始位置由固定随机种子生成，每 5 秒更新部分车辆位置。接入真实系统时，应在该数据边界增加接口适配层，不要把网络请求散落到展示组件中。

地图车辆图标位于 `public/assets/map/vehicles/`，按用户指定从本地株洲大屏项目复用公交、出租、网约、危货、班线客运和旅游包车六类透明定位图标。聚合与单车统一使用百度官方 `@bmapgl-plugin/cluster`：聚合点注入本项目聚合环，非聚合点由百度 WebGL `PointIconLayer` 绘制。


## 项目构建-123456


```bash
npm run build
```

目标浏览器为当前版本 Chrome 和 Edge。页面始终保持 3840×1080 三舱设计画布；较小桌面窗口将整张画布等比缩放并居中，不切换双栏或纵向滚动。
